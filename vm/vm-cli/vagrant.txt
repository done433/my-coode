# הפעלה מחדש של המכונה הווירטואלית בתיקייה הנוכחית כדי להחיל שינויי הגדרות
vagrant reload

# ניקוי ה"זיכרון" של Vagrant והסרת מכונות ישנות או פגומות שכבר לא קיימות במערכת מהרשימה הגלובלית
vagrant global-status --prune

# הצגת רשימה של כל המכונות הווירטואליות המנוהלות על ידי Vagrant במחשב ומצבן (רצות/כבויות)
vagrant global-status

# הצגת רשימת כל ה"בוקסים" (אימג'ים/תבניות של מערכות הפעלה) שהורדו למחשב שלך
vagrant box list

# הסרה מוחלטת של בוקס ספציפי מהמחשב, כולל כל הגרסאות שלו ובאופן מאולץ (יש להחליף את <שם_הקופסה>)
vagrant box remove <שם_הקופסה> --all --force

# מחיקה והשמדה מוחלטת של המכונה הווירטואלית בתיקייה הנוכחית (מוחק את הדיסק הווירטואלי)
vagrant destroy -f

# כיבוי כפוי ומיידי של המכונה הווירטואלית בתיקייה הנוכחית (כמו לנתק מהחשמל)
vagrant halt --force

# כיבוי מסודר של המכונה ולאחר מכן הדלקה מחדש שלה ברצף אחד
vagrant halt && vagrant up

# התחברות ב-SSH ישירות לתוך הטרמינל של המכונה הווירטואלית הפעילה בתיקייה הנוכחית
vagrant ssh
